# 学习路线图

底层路径很简单：**先把输入打开，再把能力练出来，最后把能力放进真实生活里检验。**

## 分级课程体系（CEFR）

| 级别 | 主题 | 学完你能做什么 |
|---|---|---|
| **L0 准备** | 字母、Phonics 自然拼读、IPA 音标、工具 App | 见词能读、听音能写，发音有地基 |
| **A1 入门** | 1000 核心词、be/一般现在、问候、数字时间 | 自我介绍、简单问答 |
| **A2 基础** | 2000 词、过去/将来时、比较级、简单阅读 | 讲清楚一件日常小事 |
| **B1 进阶** | 3500 词、完成时/被动/条件句、段落写作 | 写邮件、抓听力主干 |
| **B2 中高级** | 5000+ 词、长难句、议论文、新闻听力 | 清晰表达观点 |
| **C1+** | 原版书/播客/论文、写作润色 | 接近母语流畅度 |

## 每一级的标准结构

```
levels/a1/
├── overview.md      # 这一级"你能做什么"清单
├── vocabulary.md    # 词表（驱动闪卡）
├── grammar.md       # 语法 + 例句
├── listening.md     # 分级听力 + 跟读脚本
├── speaking.md      # 口语 drills
├── writing.md       # 写作模板 + 批改要点
└── checkpoint.md    # 自测过关，才能进下一级
```
