# 如何使用本站点

## 第一次来？

1. 读一遍 [学习理念](/guide/philosophy)，校准方向。
2. 打开 [路线图](/guide/roadmap)，找到自己当前的级别。
3. 从当前级别的第一章开始，**每章只做一个练习**，留下一个可检查的输出。

## 日常节奏

- **每天**：打开 [每日打卡](/drills/day-001)，完成 1 组词族卡 + 1 句听写 + 1 段跟读。
- **每周**：只选一个小目标，读一章、做一练、写一句。
- **定期**：回到旧章节重读，不同阶段会有不同答案。

## 怎么"练"而不是"看"

- 词族卡：先看中心词，猜同族词，再翻转核对例句。
- 闪卡：盖住中文说英文，盖住英文说中文，错的分开标记。
- 测验：先独立做，再对答案，把错的写进错题本。

> 收藏不等于学会。动笔、动口、动脑，才算真的在学。
