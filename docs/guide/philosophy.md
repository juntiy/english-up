# 学习理念

english-up 不卖焦虑、不承诺捷径。它想交付的是一套**可执行的训练系统**。

## 四条核心原则

1. **输入 → 输出 → 作品 → 复盘**
   先打开输入（听、读），再训练输出（说、写），把能力落成作品（文章、对话、项目），最后定期复盘。

2. **主动回忆 + 间隔重复**
   不靠反复"看"，而靠反复"提取"。看懂不等于记住，能背出来、用出来才算。

3. **最小可用单元**
   每天 15–30 分钟，一个微目标即可推进。比"周末突击 5 小时"有效得多。

4. **以用促学**
   每一级都要能"做出来、说得出、写得明"。语言是工具，用起来才会长在自己身上。

## 为什么是"词族"而不是"单词表"

普通单词表是线性死记；**词族（Word Family）** 用相同的词尾/音韵模式，把一个词变成一棵树。
记住 `deep`，就能顺藤摸瓜带出 `sheep / sleep / keep / jeep`。详见 [词族卡 Demo](/demo/word-family)。
