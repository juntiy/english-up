# A1 核心词汇（按主题）

下面按主题列出 A1 阶段最高频的词汇。每天攻克 1–2 组即可，配合 [L0 词族卡](/levels/l0/phonics) 练拼读。完整 1000 词目标靠日常积累，这份是**必会的种子清单**。
