# B1 进阶 · 概览

> **学完你能做什么**：写一封结构清楚的邮件；抓住英语新闻/对话的主干信息；用完成时和被动语态描述经历与事实；用条件句表达「如果…就…」。

## 本级别路线图

| 模块 | 核心 |
|---|---|
| 📚 词汇 | 在 A2 约 2000 词基础上扩到约 3500 词，加入抽象词、职场/学术高频词、同义词辨析 |
| 📐 语法 | 现在/过去完成时、被动语态、条件句（一/二型）、定语从句入门、间接引语 |
| 🎧 听力 | 常速对话、新闻简报、播客片段，训练「抓主干、略细节」 |
| 🗣️ 口语 | 表达观点与理由、描述经历、协商与建议 |
| ✍️ 写作 | 段落结构（主题句+支撑+结论）、正式/非正式邮件、短议论文 |
| ✅ 自测 | 过关测验，确认能写邮件、抓听力主干 |

## 和 A2 的区别

- A2 是「单句、线性时间」。
- B1 是「连接、视角、完成」：**我已经做了 / 这事被完成了 / 如果…我就…**。

## 学习建议

1. 语法重点攻克**完成时**与**被动**——这是中阶的分水岭。
2. 听力从「慢速」切到「常速」，允许漏词，只抓 who/what/why。
3. 写作练「段落」而非「句子」：每段一个中心 + 两三个支撑。
4. 学完做底部自测，过关再进 B2。
