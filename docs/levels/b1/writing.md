# B1 写作：段落与邮件

B1 写作的核心是**从句子到段落**——一段有一个中心，用支撑句展开，最后收尾。

## 1. 段落结构公式

```
[主题句] 一句话点明本段中心。
[支撑1] 解释 / 举例 / 数据。
[支撑2] 另一个角度或反面。
[结论] 一句话收束（可选）。
```

**示例**：
> *(主题)* Online learning **has become** popular. *(支撑1)* **For example**, many workers **take** courses after work. *(支撑2)* **However**, it **requires** self-discipline. *(结论)* So it suits motivated learners.

## 2. 正式 vs 非正式邮件

**非正式（朋友）**：
```
Hi Anna,
Thanks for your message! I'm free on Saturday. Shall we meet at 2?
Cheers,
Luke
```

**正式（职场/陌生）**：
```
Dear Mr. Smith,
I am writing to confirm our meeting scheduled for Friday at 3 p.m.
Please let me know if this time suits you.
Yours sincerely,
Luke Chen
```

## 3. 短议论文（B1 写作高频）

题目：*Is recycling important?*
```
I believe recycling is important for three reasons.
First, it reduces waste in landfills. For example, paper can be reused.
Second, it saves natural resources such as trees and water.
Finally, it raises public awareness of the environment.
In conclusion, recycling benefits both society and the planet.
```

## 写作自查清单

- [ ] 每段有清晰的主题句？
- [ ] 完成时 / 被动用对地方了？
- [ ] 连接词（because / however / for example）用上了？
- [ ] 正式/非正式语气匹配对象？
- [ ] 拼写与标点正确？

::: warning 常见病
B1 写作最大问题是「流水句」——一堆简单句堆砌。强迫自己每段用 1 个连接词 + 1 个完成时/被动，质感立刻不同。
:::
