# B1 核心词汇（约 3500 词精选子集）

B1 的词汇从「具体事物」走向「抽象与功能」：观点、原因、程度、职场。下面按主题列种子词，建议配合 [Anki 导出](/guide/roadmap) 系统刷。

## 1. 观点与态度
- agree / disagree / suggest / recommend / prefer / doubt / suppose / believe / expect / realize
- **例句**：I **suggest** we **postpone** the meeting.

## 2. 原因与结果
- because / since / as / so / therefore / result / cause / effect / reason
- **例句**：It rained, **so** the match was **canceled**.

## 3. 程度与频率（更细）
- slightly / fairly / rather / quite / extremely / gradually / immediately / eventually
- **例句**：The weather **gradually** became warmer.

## 4. 职场与学习
- meeting / deadline / project / report / customer / colleague / train / skill / degree / research / achieve / goal
- **例句**：We **achieved** our **goal** ahead of the **deadline**.

## 5. 社会与生活
- government / environment / pollution / recycle / community / society / culture / tradition / policy
- **例句**：The **government** introduced a new **policy** on **recycling**.

## 6. 科技与媒体
- device / software / update / download / website / social media / data / online / digital
- **例句**：I **downloaded** the **software** **update** yesterday.

## 7. 情感与关系（更细）
- relationship / confident / embarrassed / disappointed / proud / grateful / jealous / lonely
- **例句**：She was **proud** of her **achievement**.

## 8. 同义词辨析（B1 重点）
| 词 | 区别 |
|---|---|
| big / large / huge | 程度递增，huge 最大 |
| say / tell / speak / talk | say 接内容，tell 接人，speak/talk 接语言/对话 |
| job / work / career | job 具体职位，work 泛指劳动，career 职业生涯 |
| rent / hire / borrow | rent 租长物，hire 雇/租服务，borrow 借来 |

::: tip 记忆建议
B1 词汇 bonus 在「搭配」：不要背 lonely，要背 *feel lonely*；不要背 achieve，要背 *achieve a goal*。记「词 + 它的固定搭档」。
:::
