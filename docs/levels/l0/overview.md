# L0 准备 · 发音地基

> **目标**：在背任何单词之前，先让"见词能读、听音能写"成为肌肉记忆。这是避开"哑巴英语"的关键一步。

## 🎯 学完 L0 你能做什么

- [ ] 准确读出 26 个字母及其常见发音
- [ ] 用自然拼读（Phonics）拼出 CVC 单词（如 cat, dog, sit）
- [ ] 认得 IPA 基础元音 / 辅音符号，能查音标
- [ ] 用 TTS 或真人音频对照矫正自己的发音
- [ ] 听音能写出对应的词族（如听到 /kæt/ 写出 cat）

## 💡 起点建议

1. 先玩一下 [词族卡 Demo](/demo/word-family)（首页 → 词族卡 Demo），感受"一个词带一族"的记忆方式。
2. 然后按顺序走：**字母 → 音标 → 拼读规则 → 词族卡 → 听音 → 自测**。
3. 每天 15–30 分钟，一组词族即可推进，不必一次刷完。

> L0 不求"背多少词"，求"发音系统就位"。地基稳了，A1 开始的 1000 核心词会学得极快。
