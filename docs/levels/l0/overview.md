# L0 准备 · 发音地基

> 目标：在背任何单词之前，先让"见词能读、听音能写"成为肌肉记忆。

## 你能做什么（完成后）

- [ ] 准确读出 26 个字母及常见字母组合
- [ ] 用自然拼读（Phonics）拼出 CVC 单词（如 cat, dog, sit）
- [ ] 认得 IPA 基础元音/辅音符号
- [ ] 用 TTS 或真人音频对照矫正自己的发音

## 模块清单

| 模块 | 内容 | 状态 |
|---|---|---|
| 字母与发音 | A–Z 发音、易混音对比 | 规划中 |
| 自然拼读 | CVC、CVCE、常见词族（-at, -an, -ig, -op, -ee, -eep…） | 🚧 词族卡已可用 |
| IPA 音标 | 元音/辅音表、例词音频 | 规划中 |
| 工具准备 | 词典 App、TTS、跟读工具推荐 | 规划中 |

## 起点建议

先做 **词族卡 Demo**（首页 → 词族卡 Demo），感受"一个词带一族"的记忆方式，再进入系统学习。
