# 听音训练（Listening）

"听音能写"是 L0 的硬指标。训练方法是 **最小对立对（minimal pairs）**——只差一个音的两个词，反复听、反复辨。

## 方法：三步听写法

1. **听**：用 [词族卡](./phonics) 的 🔊 听一个词（先关掉文字）。
2. **写**：凭发音写出单词（或用音标记下来）。
3. **对**：翻面看答案，错了就多听两遍，找差异。

## 最小对立对练习表

每天挑 1 组，听音辨词：

| 组别 | 词对 | 差异音 |
|---|---|---|
| 长短 i | sheep / ship | /iː/ vs /ɪ/ |
| 长短 a | cap / cape | /æ/ vs /eɪ/ |
| 长短 o | hop / hope | /ɒ/ vs /əʊ/ |
| 清浊 th | think / sink | /θ/ vs /s/ |
| 鼻音 | sin / sing | /n/ vs /ŋ/ |
| 卷舌 | red / led | /r/ vs /l/ |

## 进阶

- 听一句慢速材料（VOA Learning English），写下来能拼对的词越多越好。
- 用 [书写页](./writing) 把听写的词工整抄一遍，手耳并用。
