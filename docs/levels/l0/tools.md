# 工具与 App 推荐（L0 必备）

发音地基阶段，几个免费好用的工具能让你事半功倍。

## 📖 词典类（查音标 + 真人发音）

| 工具 | 用途 | 推荐理由 |
|---|---|---|
| **Cambridge Dictionary** | 英式/美式音标 + 真人发音 | 音标规范，例句丰富 |
| **Youdao / 有道词典** | 中英互查、发音 | 国内访问快，适合入门 |
| **欧路词典（Eudic）** | 离线词库、划词 | 可装多本权威词典 |

## 🔊 发音矫正

| 工具 | 用途 |
|---|---|
| **ELSA Speak** | AI 打分你的发音，指出哪个音不准 |
| **英语流利说** | 跟读打分，国内常用 |
| **Forvo** | 全球真人发同一个词，听各种口音 |

## 🗣️ 跟读 / 影子跟读

| 工具 | 用途 |
|---|---|
| **Spotify / Apple Podcasts** | 找慢速英语播客（如 VOA Learning English） |
| **YouTube** | 搜 "slow English for beginners" |
| 本站的 🔊 按钮 | 每个词族卡内置 Web Speech TTS，随时听 |

## ✍️ 书写 / 拼写

| 工具 | 用途 |
|---|---|
| 纸笔 + [书写页](./writing) | 手写字母，肌肉记忆 |
| **Anki**（见仓库 `scripts/export-anki.mjs`） | 把词族导出成卡，离线刷 |

## 💡 使用建议

1. **固定一个主词典**（推荐 Cambridge 或有道），查词时一定点发音听。
2. **每天 5 分钟 ELSA**：专攻你最易错的 1–2 个音。
3. **TTS 不能代替真人**：本站 🔊 是机器音，正式学请搭配 Cambridge / Forvo 的真人音。

> 工具是辅助，**每天开口 15 分钟**比装 10 个 App 都重要。
