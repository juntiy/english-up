# 字母与发音（Alphabet & Sounds）

英语 26 个字母分 **元音字母**（A E I O U）和 **辅音字母**。字母名（name）和字母音（sound）常常不同——比如字母 C 叫 /siː/，但在 cat 里发 /k/。这正是自然拼读要解决的核心。

## 易混音对比（初学者高频踩坑）

| 易混 | 区别要点 | 例词 |
|---|---|---|
| /iː/ vs /ɪ/ | 长音 vs 短音 | see / sit |
| /æ/ vs /e/ | 嘴张大 vs 略扁 | cat / pet |
| /v/ vs /w/ | 上齿咬下唇 vs 圆唇 | van / wan |
| /θ/ vs /s/ | 舌尖吐气咬舌 vs 平舌 | think / sink |
| /r/ vs /l/ | 卷舌 vs 舌尖抵上颚 | red / led |
| /n/ vs /ŋ/ | 舌尖抵上颚 vs 舌根抵软颚 | sin / sing |

## 练习方法

1. **字母歌**：先把 26 个字母名唱熟（A B C D…）。
2. **名音对照**：指着字母说名，再举一个它的"常见音"例词（C → /k/ → cat）。
3. **易混专项**：每天挑 1 组易混音，对着镜子看口型，录音对比。
