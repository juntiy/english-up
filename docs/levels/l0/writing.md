# 书写与拼写（Writing）

L0 的"写"分两层：**字母书写**（手写体肌肉记忆）和 **音素拼写**（听音写词）。

## 1. 字母书写

- 打印或手画四线三格，每天临摹 26 个字母的大小写。
- 注意易混形的书写区别：**b / d / p / q**（占格和朝向不同）。
- 目标：能不看范本、工整写出任意字母。

### 占格速记

| 类型 | 字母 |
|---|---|
| 中格（a, c, e, m, n, o, r, s, u, v, w, x, z） | 小写主体在中格 |
| 上伸（b, d, f, h, k, l, t） | 向上冲出中格 |
| 下延（g, p, q, y, j） | 向下拖出中格 |
| 占全格（大写 A–Z、i, j 点） | 顶天立地 |

## 2. 音素拼写（听音写词）

听到一个词，按"音素 → 字母"拆写：

- /kæt/ → 听到 /k/ 写 c，/æ/ 写 a，/t/ 写 t → **cat**
- /bæk/ → b + a + ck → **back**（注意 /k/ 在词尾常写 ck）
- /sɪŋ/ → s + i + ng → **sing**（鼻音 ng 是一个组合）

### 拼写规则小结

| 规律 | 例 |
|---|---|
| 词尾 /k/ 前是短元音 → 写 ck | back, sick, lock |
| 鼻音 /ŋ/ → 写 ng | sing, ring, long |
| /ʃ/ → sh | ship, fish |
| /tʃ/ → ch | chat, rich |
| 长元音 + 静音 e | cake, bike, note |
