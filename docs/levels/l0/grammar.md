# 拼读规则（Phonics Rules）

自然拼读不是死记硬背，而是几条可复用的规则。掌握它们，大部分单音节词都能"见词能读"。

## 1. CVC 结构（ consonant-vowel-consonant ）

最常见的单词骨架：**辅音 + 短元音 + 辅音**。中间的元音读**短音**。

- c-a-t → /kæt/（a 读短音 /æ/）
- d-o-g → /dɒg/（o 读短音 /ɒ/）
- p-i-g → /pɪg/（i 读短音 /ɪ/）

> 词族卡里的短元音组（short-a/e/i/o/u）全是 CVC 结构。

## 2. Magic E（静音 e / 长元音）

词尾加 **不发音的 e**，中间的元音变成**长音**（字母本音）：

| 短音 | + e | 长音 |
|---|---|---|
| cap /kæp/ | → cape /keɪp/ | a 读 /eɪ/ |
| bit /bɪt/ | → bite /baɪt/ | i 读 /aɪ/ |
| hop /hɒp/ | → hope /həʊp/ | o 读 /əʊ/ |
| cut /kʌt/ | → cute /kjuːt/ | u 读 /juː/ |

口诀：**"e 让元音变长，自己沉默。"**

## 3. 辅音组合（Blends & Digraphs）

- **Blends（连读）**：两个辅音挨着，各自发声但快速连读 → `bl`(black) `st`(star) `tr`(tree)
- **Digraphs（合读）**：两个字母**发一个音** → `sh`(/ʃ/ ship) `ch`(/tʃ/ chat) `th`(/θ/或/ð/ think/this) `ck`(/k/ back) `ng`(/ŋ/ sing)

## 4. 常见元音组合

| 组合 | 发音 | 例 |
|---|---|---|
| -ay | /eɪ/ | day, play |
| -ee | /iː/ | see, tree |
| -oo | /ʊ/ 或 /uː/ | book, blue |
| -ai | /eɪ/ | rain, train |
| -oa | /əʊ/ | boat, coat |
| -ou | /aʊ/ | house, mouth |

## 5. 拆分音节（解码长词）

遇到长词，先按元音拆成音节，再逐段拼：

- **pic-ture** → /ˈpɪk.tʃə/
- **bas-ket** → /ˈbɑː.skɪt/
- **win-dow** → /ˈwɪn.dəʊ/
