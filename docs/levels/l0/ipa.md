# IPA 国际音标（基础表）

音标是"发音的字典"。L0 阶段不需要背全表，只要认得下面这些**基础符号**，能查、能跟读就够了。

## 元音（Vowels）

|---|---|---|
| /iː/ | see, sheep | 嘴角咧开，长音 |

| /e/ | bed, net | 嘴微张 |
| /æ/ | cat, hat | 嘴张大，舌尖抵下齿 |
| /ʌ/ | cup, sun | 自然放松 |

## 怎么用

1. **查词必看音标**：遇到生词，先看 /.../ 里的音标再读，别用字母瞎猜。
2. **对照词族卡**：[词族卡](./phonics) 里每个词都标了音标，跟着读、对着表核对。
3. **弱读 /ə/**：英语里大量虚词（a, the, of）在非重读时变成 /ə/，这是"地道感"的来源。

> 配合 [字母与发音](./alphabet) 和 [拼读规则](./grammar) 一起练，音标会越看越熟。
