# A2 核心词汇（约 2000 词精选子集）

A2 的重心是**把词汇量从 1000 拉到 2000**，覆盖更生活化的主题。下面按主题列出「必须掌握」的种子词，完整词表建议配合 [Anki 导出](/guide/roadmap) 与 [词族卡](/levels/l0/phonics) 一起刷。

## 1. 旅行与交通
- plane / train / bus / taxi / subway / station / airport / ticket / passport / luggage / hotel / map / trip / holiday / beach / mountain
- **例句**：We took the **train** to the **beach** for our **holiday**.

## 2. 购物与金钱
- shop / store / market / price / cheap / expensive / buy / sell / pay / cost / money / wallet / change / size / color / clothes / shoe
- **例句**：This shirt is too **expensive**; do you have a **cheaper** one?

## 3. 食物与餐饮
- breakfast / lunch / dinner / snack / hungry / thirsty / cook / boil / fry / order / menu / bill / vegetables / fruit / meat / rice / soup
- **例句**：I **cooked** dinner and **boiled** some rice.

## 4. 健康与身体
- head / stomach / tooth / back / hurt / pain / sick / tired / cold / fever / doctor / medicine / rest / exercise / healthy
- **例句**：My **head** **hurts**; I think I have a **cold**.

## 5. 天气与季节
- sun / rain / snow / wind / cloud / hot / cold / warm / cool / weather / spring / summer / autumn / winter
- **例句**：The **weather** is **warm** and **sunny** today.

## 6. 工作与日常
- job / work / office / boss / colleague / meeting / computer / email / phone / busy / late / early
- **例句**：I was **late** for the **meeting** this morning.

## 7. 情绪与社交
- happy / sad / angry / worried / bored / excited / surprised / tired / friendly / alone / together
- **例句**：She was **surprised** but **happy** to see us.

## 8. 家与物品
- kitchen / bedroom / bathroom / balcony / furniture / chair / shelf / mirror / lamp / key / lock / neighbor
- **例句**：Our **neighbor** is very **friendly**.

## 9. 时间与频率
- always / usually / often / sometimes / never / soon / later / already / yet / ago
- **例句**：I **often** walk to work, but **never** on rainy days.

## 10. 描述与比较
- big / small / tall / short / long / fast / slow / good / bad / better / best / worse / clean / dirty
- **例句**：This road is **shorter** but **slower** than the highway.

::: tip 记忆建议
A2 词汇不要死背列表。每词造 1 句「过去 + 将来」的组合句，例如：*Yesterday I **bought** a cheap shirt; tomorrow I **will wear** it.* 一句同时练词汇 + 时态。
:::
