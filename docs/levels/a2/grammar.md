# A2 语法三件套

A2 的语法核心是**让句子动起来**——过去、将来、比较。下面每个点都配「结构 + 例句 + 易错提醒」。

## 1. 一般过去时（Past Simple）

**规则动词**：动词 + `-ed`
- work → worked · play → played · watch → watched

**不规则动词**（A2 必须背熟的高频）：
| 原形 | 过去式 | 例句 |
|---|---|---|
| go | went | I **went** to the market. |
| eat | ate | She **ate** an apple. |
| buy | bought | He **bought** a book. |
| see | saw | We **saw** a film. |
| have | had | They **had** lunch. |
| do | did | I **did** my homework. |
| come | came | She **came** home late. |

**否定 / 疑问**：用 did（已经含过去，动词回原形）
- I **didn't go** to school. / **Did** you **eat** breakfast?

::: warning 易错
❌ *I went to school yesterday and I see my friend.*（同一段过去叙事，后面动词也要过去时）
✅ I went to school yesterday and **saw** my friend.
:::

## 2. 一般将来时（Future）

两种说法，意思略有不同：

**will + 动词原形** —— 临时决定 / 预测
- I **will help** you. （你开口求助，我当场决定）
- It **will rain** tomorrow. （预测）

**be going to + 动词原形** —— 已有计划 / 有迹象
- I **am going to** visit my grandma this weekend. （早就计划好）
- Look at the sky! It **is going to** rain. （乌云是迹象）

::: tip 选择口诀
「已经想好」用 going to；「现在才决定 / 瞎猜」用 will。
:::

## 3. 比较级（Comparative）

**短形容词**：原级 + `-er` + than
- tall → **taller than** · cheap → **cheaper than** · fast → **faster than**

**长形容词（2+ 音节）**：more + 原级 + than
- expensive → **more expensive than** · beautiful → **more beautiful than**

**不规则比较**：
- good → **better than** · bad → **worse than** · far → **farther/further than**
- many/much → **more than** · little → **less than**

**最高级**：the + 最高级
- the **tallest** · the **most expensive** · the **best**

::: warning 易错
❌ *This book is more cheaper than that.*（more 和 -er 不能叠加）
✅ This book is **cheaper than** that.
:::

## 4. 情态动词（can / must / should）

| 词 | 意思 | 例句 |
|---|---|---|
| can | 能 / 可以 | I **can** swim. |
| must | 必须 | You **must** wear a seatbelt. |
| should | 应该 | You **should** see a doctor. |

否定：can't / mustn't / shouldn't。疑问把情态动词提前：**Can** you help me?

::: tip 小结练习
用三句话串起今天学的：*Yesterday I **went** to a shop. The shoes were **cheaper** there. Tomorrow I **will buy** them.* —— 这就是「讲清一件小事」的能力。
:::
