# A2 基础级 · 概览

> **学完你能做什么**：用简单的过去/将来时，把一件日常小事（昨天做了什么、明天要去哪）讲清楚；读懂短短信、便条、简单的故事；能比较两样东西的好坏多少。

## 本级别路线图

| 模块 | 你要掌握的核心 |
|---|---|
| 📚 词汇 | 在 A1 的 1000 词基础上，扩充到约 2000 词（旅行、购物、健康、天气、工作、情绪等主题） |
| 📐 语法 | 一般过去时、一般将来时（will / be going to）、形容词/副词比较级、情态动词 can/must/should |
| 🎧 听力 | 慢速短对话、天气预报、简单广播通知 |
| 🗣️ 口语 | 描述过去经历、计划未来、表达偏好与建议 |
| ✍️ 写作 | 写短信/邮件、日记式短段落、购物清单与说明 |
| ✅ 自测 | 过关测验，确认能独立用过去/将来时讲一件小事 |

## 和 A1 的区别

- A1 是「现在」：我是、我有、我喜欢。
- A2 是「时间流动」：**我昨天去了…、我明天要去…、这个比那个更…**。

## 学习建议

1. 先过语法三件套：过去时 → 将来时 → 比较级。
2. 每天用 3 句话写「昨天 / 今天 / 明天」日记，强制使用三个时态。
3. 词族卡继续刷（L0 的 71 族是发音地基，A2 重点是词汇量扩张）。
4. 学完直接做本页底部的自测，过关再进 B1。
