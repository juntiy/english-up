# A2 写作：短信、日记、清单

A2 写作不要求长文，目标是**写清楚、写对时态**。三个最实用的场景：

## 1. 短邮件 / 短信

**结构**：问候 → 目的 → 细节 → 结尾

```
Hi Tom,

Sorry I **was** late yesterday. The bus **was** full and I **missed** it.
Can we **meet** at 3 pm tomorrow? I **will bring** the book.

See you,
Luke
```

## 2. 日记式短段落（强制练三时态）

每天写 3 句：昨天 / 今天 / 明天

```
Yesterday I **cooked** dinner for my family.
Today I **am** tired but happy.
Tomorrow I **am going to** visit my friend.
```

## 3. 购物清单 / 说明

```
Shopping list:
- 2 kilos of rice
- some vegetables
- a cheaper shirt (size M)

Note: The red one was too expensive.
```

## 写作检查清单（写完后自查）

- [ ] 过去的事用了过去式（-ed 或不规则）？
- [ ] 将来的事用了 will / going to？
- [ ] 比较时加了 -er / more ... than？
- [ ] 大小写、句末标点正确？
- [ ] 每句主谓齐全（谁 + 做了什么）？

::: warning 常见病
A2 写作最大问题是「时态混搭」：一段讲昨天，突然出现原形动词。写完通读一遍，把所有「过去事件」的动词统一成过去式。
:::
