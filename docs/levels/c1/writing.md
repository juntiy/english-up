# C1+ 写作：风格化与润色

C1+ 写作的差距在**编辑**——初稿人人能写，高手赢在「三轮润色」。

## 三轮编辑法

**第 1 轮 · 准确（Accuracy）**
- 词汇搭配对吗？（make/do, heavy/strong）
- 时态、语态、单复数无误？
- 语义 nuance 是否精准？

**第 2 轮 · 连贯（Cohesion）**
- 段落间有逻辑流吗？
- 连接是否「隐形」（指代/平行）而非堆 and/but？
- 节奏有长短句交错吗？

**第 3 轮 · 风格（Style）**
- 语域匹配对象吗？（学术/商务/创意）
- 有无可删的废话？（very, really, in order to → to）
- 有没有一句「让人记住」的好句？

## 风格化示范

初稿：*We need to think about the environment. Pollution is bad. We should do something.*

润色后：*The environment demands our urgent attention. **As pollution escalates**, inaction is no longer an option.* （名词化 + 分裂结构 + 正式语域）

## 创意写作元素

- **show, don't tell**：❌ *He was angry.* → ✅ *His knuckles whitened around the glass.*
- **具体 > 抽象**：用感官细节替代形容词。
- **声音 (voice)**：找到你自己的句式偏好与节奏。

## 评论/散文结构

```
钩子（hook）：一句抓人的开场
立论：明确立场或主题
展开：2–3 个有细节的支撑
转折/深化：一层更妙的思考
收尾：余韵或升华，不啰嗦
```

## 自查清单

- [ ] 三轮编辑都过了？
- [ ] 有没有一句「废话」可删？
- [ ] 语域一致且匹配读者？
- [ ] 有无一个令人印象深的表达？

::: warning 常见病
C1+ 写作者常「过度装饰」——硬塞难词反而显假。高手追求**精准的朴素**：用最普通的词，说最准确的话。
:::
