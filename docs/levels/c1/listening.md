# C1+ 听力：多口音与言外之意

C1+ 听力挑战不在「速度」，而在**口音多样性**与**隐含态度**。

## 训练材料（多口音）

| 口音 | 来源 | 特征 |
|---|---|---|
| 英式 RP | BBC、英剧 | 清晰但元音独特 |
| 美式 | 好莱坞、播客 | 卷舌 r、flat a |
| 澳式 | ABC News | 升调陈述、元音偏移 |
| 印度/东南亚 | 国际会议 | 节奏重、辅音硬 |
| 苏格兰/爱尔兰 | 纪录片 | 语调跳跃 |

**策略**：每种口音各听 30 分钟，建立「听觉宽容度」。

## 抓言外之意（Implicature）

英语常「话里有话」：
- *"That's an interesting idea."* → 往往意思是「我不赞同，但客气」。
- *"We'll see."* → 实际是「大概率不会」。
- 升调陈述 *"You finished?"* → 表惊讶/质疑，非纯询问。

训练：听后自问「他真正想表达什么？」

## 无字幕影视精听法

1. 盲看 1 遍：抓情节与态度。
2. 二看开英文字幕：核对理解偏差。
3. 摘 5 个「没听出的词/连读」，单独练。
4. 三看关字幕：确认已消化。

## 讲座/学术听力

- 抓 **signposting**（路标词）：*Today I'll argue... / The key point is... / To sum up...*
- 这些词标出结构，帮你「快进」冗余。

::: tip 卡住信号
若某口音完全听不懂，先用该口音的**慢速材料**过渡（如 BBC Learning English 的印式/非母语专题），再回常速。
:::
