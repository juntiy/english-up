# C1+ 词汇与选材指南

C1+ 阶段，**词汇量已不是瓶颈**，真正要练的是 **nuance（语义细微差别）、collocation（地道搭配）、register（文体）**。

## 1. 语义细微差别（Nuance）

近义词在不同语境不可互换：

| 词 | 细微差别 |
|---|---|
| thin / slim / skinny | thin 中性；slim 褒义（苗条）；skinny 贬义（皮包骨） |
| angry / annoyed / furious | 程度递增：恼火 → 生气 → 暴怒 |
| house / home / residence | house 建筑；home 情感归属；residence 正式/法律 |
| ask / request / demand | 礼貌递增，语域不同 |

**练习**：遇到近义词，逼自己说出「它们不能互换的那一刻」。

## 2. 地道搭配（Collocation）

英语是「词搭伙」的语言，固定搭档不能乱换：

- ❌ *do a mistake* → ✅ **make** a mistake
- ❌ *strong rain* → ✅ **heavy** rain
- ❌ *quick food* → ✅ **fast** food
- ❌ *raise a child*（对）→ 但 *bring up* a child 更自然
- ✅ **commit** a crime / **keep** a promise / **break** the news

## 3. 原版选材清单（每月轮换）

| 类型 | 推荐 | 目的 |
|---|---|---|
| 小说 | 《The Alchemist》《Animal Farm》《Charlotte's Web》 | 文学语感、叙事节奏 |
| 非虚构 | 《Sapiens》《Outliers》《Atomic Habits》 | 论证结构与学术词 |
| 期刊 | The Economist / BBC Culture / Aeon | 评论文体、时新词 |
| 播客 | The Daily / Radiolab / Lex Fridman | 多口音、长访谈 |
| 论文 | Google Scholar 入门综述 | 学术写作范式 |

## 4. 文体意识（Register）

同一件事，三种写法：
- 口语：*Kids gotta learn stuff early.*
- 通用：*Children should learn early.*
- 正式：*It is advisable that children acquire foundational skills at an early stage.*

::: tip 高阶记忆法
C1+ 不再「背单词」，而是**建语料库**：用笔记 App 收集「好句 + 其语境 + 为何好」，每周仿写 3 句。量不在多，在「能用」。
:::
