# C1+ 高级 · 概览

> **学完你能做什么**：近乎母语地阅读原版书、论文、长文；听懂无字幕影视与专业讲座；写出有个人风格、修辞考究的文章；在任意场合自如、精准、有感染力地表达。

## 本级别路线图

| 模块 | 核心 |
|---|---|
| 📚 词汇 | 8000+ 词，学术/文学/专业术语，nuance（语义细微差别），collocation 地道搭配，文体意识 |
| 📐 语法 | 全面巩固 + 风格化运用（省略、分裂句、混合虚拟、文学性倒装），重点在「得体」而非「正确」 |
| 🎧 听力 | 无字幕影视、专业讲座、不同口音（英/美/澳/印），抓言外之意与语气 |
| 🗣️ 口语 | 即兴长篇、幽默反讽、谈判说服、跨文化得体表达 |
| ✍️ 写作 | 风格化散文、评论、论文、创意写作，编辑润色能力 |
| ✅ 自测 | 过关测验，确认能写风格化评论、听懂多口音 |

## 和 B2 的区别

- B2：能说服、结构好。
- C1+：**有风格、有深度、有分寸**——知道什么场合说什么话，能读能写「原汁原味」的英语。

## 学习建议

1. **大量输入原版**：每月 1–2 本原版书 + 固定播客/期刊。
2. **精读 + 仿写**：摘抄好句，分析 why it works，模仿其节奏。
3. **润色训练**：写完后做「三轮编辑」（准确→连贯→风格）。
4. 学完做底部自测，确认接近流利。
