# B2 中高级 · 概览

> **学完你能做什么**：就广泛话题清晰、详细地表达观点；读懂新闻与议论文并拆解长难句；写出结构严谨、有说服力的文章；在英语环境里自然社交、谈判、陈述。

## 本级别路线图

| 模块 | 核心 |
|---|---|
| 📚 词汇 | 冲 5000+ 词，加入学术/专业词、习语(idioms)、短语动词(phrasal verbs)、语域(正式/口语切换) |
| 📐 语法 | 长难句拆解、非谓语动词、虚拟语气、倒装、强调句、各类从句嵌套 |
| 🎧 听力 | 新闻、纪录片、无字幕影视、专业讲座，训练「略过冗余、锁定论点」 |
| 🗣️ 口语 | 流利辩论、委婉表达、幽默与反讽、即兴演讲 |
| ✍️ 写作 | 议论文/评论文、报告、正式邮件、修辞与衔接 |
| ✅ 自测 | 过关测验，确认能写评论文、抓新闻论点 |

## 和 B1 的区别

- B1：能写段落、抓主干。
- B2：**能写论证、拆长句、切换语域**——从「能沟通」到「能说服」。

## 学习建议

1. 语法重点：**长难句拆解**与**虚拟语气**，这是读写的硬门槛。
2. 听力直接上**无字幕新闻/纪录片**，练「跳读式听」。
3. 写作练**论证结构**：论点 → 论据 → 反驳 → 结论。
4. 学完做底部自测，过关即接近流利，进 C1+。
