# B2 核心词汇（冲 5000+ 词精选子集）

B2 词汇的难点不在「量」而在「质」：**短语动词、习语、学术词、语域切换**。

## 1. 短语动词（Phrasal Verbs，B2 高频）

| 短语 | 意思 | 例句 |
|---|---|---|
| come up with | 想出 | She **came up with** a great idea. |
| carry out | 执行 | We **carried out** the plan. |
| put off | 推迟 | Don't **put off** till tomorrow. |
| figure out | 弄懂 | I can't **figure out** this problem. |
| bring about | 带来(变化) | Tech **brought about** change. |
| deal with | 处理 | He **deals with** complaints. |

## 2. 习语（Idioms，写作口语加分）

- **a piece of cake** — 小菜一碟：*The test was a piece of cake.*
- **hit the nail on the head** — 一针见血：*You hit the nail on the head.*
- **burn the midnight oil** — 开夜车：*She burned the midnight oil.*
- **the ball is in your court** — 该你决定了：*The ball is in your court now.*
- **cut corners** — 偷工减料：*Don't cut corners on safety.*

## 3. 学术/论证词

- argue / claim / propose / evidence / indicate / reveal / contrast / furthermore / nevertheless / consequently
- **例句**：The data **indicate** a trend; **nevertheless**, more research is needed.

## 4. 语域切换（Register）

| 口语 | 正式 |
|---|---|
| kids | children |
| guy | man / person |
| get | obtain / receive |
| a lot of | a great deal of |
| thing | matter / issue |

## 5. 专业/话题词（选学）

- 环境：carbon emission / sustainable / biodiversity
- 科技：algorithm / automate / cybersecurity
- 经济：inflation / fluctuate / recession

::: tip 记忆建议
B2 词汇要「成组记」：一个动词带它的短语（*carry → carry out / carry on / carry forward*），一个习语带语境。死背单词表在这个阶段收益骤降。
:::
