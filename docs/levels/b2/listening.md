# B2 听力：无字幕、抓论点

B2 听力进入**真实语速、无字幕、有冗余**的材料。目标：**不被细节淹没，锁定论点与态度**。

## 训练材料

1. **新闻**（BBC News、CNN、CGTN）——注意主持人如何「起承转合」。
2. **纪录片 / 讲座**（TED、YouTube 知识类）——信息密度高。
3. **影视剧无字幕**——练连读、略音、语气。
4. **播客**（长访谈）——练「跳听」：略过寒暄抓干货。

## 论点提取法

听任何一段，画一张极简图：

```
[说话人] → [核心观点] → [理由1] [理由2] → [态度: 支持/反对/中立]
```

例：
> *"I think remote work **is here to stay**. **Firstly**, it saves commute. **But** productivity varies. **Overall**, I'm positive."*

提取：观点=远程办公将留存；理由=省通勤；转折=效率参差；态度=总体正面。

## 连读与略音（B2 听感难点）

- *want to* → *wanna* · *going to* → *gonna* · *did you* → *didja*
- 失爆：*got to* 的 t 常不发音 → *godda*
- 同化：*not at all* → *no-ta-tawl*

## 每日训练

1. 选 2 分钟无字幕材料，盲听记「论点+态度」。
2. 二听补「理由」，三听查生词。
3. 影子跟读 1 遍，模仿连读。
4. [学习中心](/) 闯关跟读环节巩固。

::: tip 卡住信号
如果一段听 3 遍仍抓不到论点，说明材料偏难——退到 B1 常速，或开 0.75 倍速。B2 听力是「质」的飞跃，不靠硬啃。
:::
