# B2 写作：论证文与修辞

B2 写作追求**说服力**——结构清晰、论据扎实、衔接自然、语域得当。

## 1. 议论文标准结构

```
引言：背景 + 立场（thesis statement）
主体段1：论点A + 论据 + 例子
主体段2：论点B + 论据 + 例子
让步段：对方观点 + 反驳（显思辨）
结论：重申立场 + 升华
```

**示例（AI 与教育）**：
> *(引言)* Artificial intelligence **is transforming** education. *I argue* it **benefits** learners.
> *(段1)* **Firstly**, AI **provides** personalized practice. *For instance*, chatbots **explain** grammar instantly.
> *(段2)* **Furthermore**, it **frees** teachers from grading.
> *(让步)* **Admittedly**, over-reliance **weakens** thinking. *However*, used as aid, not crutch, the risk **is manageable**.
> *(结论)* **On balance**, AI **is** a powerful ally if guided well.

## 2. 衔接手段（Cohesion）

| 功能 | 词 |
|---|---|
| 递进 | furthermore / moreover / what's more |
| 转折 | nevertheless / whereas / by contrast |
| 因果 | consequently / as a result / thereby |
| 举例 | for instance / to illustrate / a case in point |
| 总结 | on balance / all things considered |

## 3. 修辞与强调

- 强调句：*It **is** critical thinking **that** AI cannot replace.*
- 倒装：*Only by practicing **can** one master a language.*
- 虚拟：*Were schools to adopt AI, learning **would** accelerate.*

## 4. 正式语域要点

- 不用缩写（do not / cannot，非 don't / can't）
- 被动更显客观：*It **has been argued** that...*
- 避免口语词（kids → children, thing → matter）

## 写作自查

- [ ] 有清晰的 thesis statement？
- [ ] 每段一个论点 + 支撑？
- [ ] 用了让步段显思辨？
- [ ] 衔接词多样不重复？
- [ ] 语域一致（正式）？

::: warning 常见病
B2 写作最大问题是「没有让步段」——一边倒的论证显得幼稚。加一段 *Admittedly... However...* 立刻显成熟。
:::
